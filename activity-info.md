# Lab Activity 1 — University Student Profile Page

## Scenario

The School of Computing & IT wants a simple webpage that introduces a student to visitors during an orientation programme.

Students must create a Student Profile Page using only:

- HTML5
- CSS3
- No JavaScript
- No Bootstrap or other frameworks
- No AI-generated code

## Learning Objectives

By the end of the activity, students should be able to:

1. Create a basic HTML5 document.
2. Use semantic HTML5 elements.
3. Organize information using headings, paragraphs, and lists.
4. Create hyperlinks and images.
5. Create a simple HTML5 form.
6. Apply CSS3 using different types of selectors.
7. Separate HTML content from CSS presentation.

## Student Requirements

- Your webpage must contain **at least 8 different HTML5 elements**, including `<div>` and `<span>`.
- Create a **responsive layout** for a mobile screen.

## Required Content

Create a student profile containing:

### 1. Header
- University name
- Page title

### 2. Navigation
- Home
- About
- Courses
- Contact

### 3. About Me
- Student name
- Programme
- Year of study
- Short biography
- Photograph

### 4. My Courses
Create a list of at least **four courses**.

### 5. Weekly Schedule
Create a table containing at least **three courses** and their class times.

### 6. Contact Me
Create a form containing:
- Name
- Email
- Message
- Submit button

### 7. Footer
- Student name
- Copyright information
